# SafeON README Media Guide

메인 `README.md`에서 사용할 이미지와 GIF의 권장 파일명입니다.

| 파일명 | 권장 내용 | 권장 비율 |
|---|---|---|
| `safeon-demo.gif` | SAFE부터 사건 리포트까지의 30초 시연 요약 | 16:9 |
| `dashboard-overview.png` | 관제 대시보드 전체 화면 | 16:9 |
| `incident-report.png` | 개별 사건 상세 리포트 | 16:9 |
| `hardware-esp32-uwb.jpg` | 초기 ESP32·UWB 프로토타입 | 4:3 또는 16:9 |
| `hardware-laptop-demo.jpg` | 최종 노트북 간 통신 시연 구성 | 4:3 또는 16:9 |
| `award.jpg` | 상장 또는 팀 수상 사진 | 4:3 |

## 작성 원칙

- ESP32·UWB 사진은 초기 프로토타입이며 최종 시연에는 사용하지 않았음을
  캡션에 명시합니다.
- 대시보드 GIF는 10~15초 내외로 편집해 자동 재생 시 핵심 흐름이 빠르게
  보이도록 합니다.
- 상장과 팀 사진을 공개하기 전에 팀원의 이름과 얼굴 공개 동의를 확인합니다.
- 이미지 가로 폭은 최소 1200px을 권장합니다.
